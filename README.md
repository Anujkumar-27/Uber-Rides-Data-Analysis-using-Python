📊 Uber Rides Data Analysis using Python
📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on Uber ride data using Python. The goal is to analyze ride patterns, user behavior, and trip characteristics through data cleaning, feature engineering, and visualization techniques.

🛠️ Technologies & Libraries Used

Python

Pandas – Data manipulation and preprocessing

NumPy – Numerical computations

Matplotlib & Seaborn – Data visualization

Scikit-learn – One-Hot Encoding for categorical variables

📂 Dataset Description

Total Records: 1156

Total Features: 7

Key Columns: START_DATE, END_DATE, CATEGORY, PURPOSE, MILES, START, STOP

🔄 Data Preprocessing & Feature Engineering

Handled missing values in categorical columns

Converted date-time columns into proper datetime format

Extracted date, hour, month, and weekday from timestamps

Created time-of-day categories (Morning, Afternoon, Evening, Night)

Removed duplicate and invalid records

Applied One-Hot Encoding to categorical features for correlation analysis

📈 Data Visualization & Analysis

Analyzed ride distribution by category, purpose, time of day, weekday, and month

Used count plots, bar plots, line plots, box plots, distribution plots, and heatmaps

Examined trip distance patterns and identified outliers

Performed correlation analysis to study relationships between numerical and encoded features

📌 Key Insights

Business rides account for the majority of Uber usage

Most trips are booked for Meetings and Meals/Entertainment

Peak ride demand occurs during afternoon hours (10 AM – 5 PM)

Ride activity is higher on weekdays compared to weekends

Most trips fall within 0–20 miles, with the highest frequency around 4–5 miles

Ride counts are significantly lower during winter months (Nov–Jan)

✅ Conclusion

This analysis highlights how Uber ride usage varies by time, purpose, distance, and season. Through effective data preprocessing and visualization, meaningful patterns were uncovered that reflect real-world user behavior. The project demonstrates strong skills in data cleaning, exploratory analysis, feature engineering, and visual storytelling using Python.
